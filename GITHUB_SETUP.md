# GitHub setup

Recommended repository name:

```text
vecpac-ae-vectrex
```

Recommended description:

```text
A three-mode Vectrex homebrew cartridge with a 30-level campaign, Jetpac and Killer Queen modes. Includes 6809 source and a .vec release.
```

## Upload

Create a **public** repository and do not ask GitHub to generate a README, `.gitignore`, or license. They are already included where needed.

Upload the contents of this folder so that `README.md` is at the repository root.

## Enable GitHub Pages

Open:

```text
Settings → Pages
```

Choose:

```text
Source: Deploy from a branch
Branch: main
Folder: /docs
```

Save the setting.

With the recommended repository name, the public game page will be:

```text
https://mmmpt.github.io/vecpac-ae-vectrex/
```

VECPAC A.E. — Vectrex
======================

VECPAC A.E. is a homebrew cartridge for the GCE/Milton Bradley Vectrex.

Included file:
  VecpacAE.vec

Game modes:
  1 GAME                  Full 30-level campaign
  2 MINI GAME JETPAC      Standalone 24-level Jetpac mode
  3 MINI GAME KILLER QUEEN Standalone Killer Queen mode

MAIN MENU
  Joystick 1 Up/Down  Select mode
  Button 4            Start

JETPAC
  Joystick 1 Left/Right  Move
  Button 1               Thrust
  Button 4               Fire laser

KILLER QUEEN
  Joystick 1 Left/Right  Move
  Button 4               Fire
  Button 1               Shield (when available)

Run the .vec file in a Vectrex emulator, or on real hardware using a
compatible flash/reprogrammable cartridge.

The Vectrex BIOS is not included.
